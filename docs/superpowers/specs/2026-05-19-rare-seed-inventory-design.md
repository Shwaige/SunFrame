# 稀有种子库存查询脚本设计

## 目标

新增一个单账号脚本，用于访问阳光牧场商店中的稀有种子页，提取当前“已有”的稀有种子 `seedId`，再逐个访问种子详情页，读取成熟时间，并直接输出到控制台。

本次范围只做单独脚本，不接入现有 `ygmc` CLI，也不支持批量账号。

## 输入

脚本使用固定的单账号凭证运行：

- `openId`
- `sid`

可通过脚本内常量或环境变量传入，优先保证能快速单账号执行。

## 页面与接口

### 1. 稀有种子商店页

入口页使用商店列表：

- `/ygmc/store/index.go`

关键参数：

- `type=0`
- `subType=2`
- `pageNo=1..n`

脚本职责：

- 读取第一页
- 解析总页数
- 逐页抓取
- 提取“已有”的稀有种子 `seedId`

### 2. 种子详情页

详情页使用商店商品详情：

- `/ygmc/store/goodsInfo.go`

关键参数：

- `id=<seedId>`

脚本职责：

- 对每个 `seedId` 访问详情页
- 解析成熟时间
- 输出 `seedId + 名称 + 成熟时间`

## 解析规则

### 商店列表页

从列表页中识别：

- 种子链接中的 `id`
- 种子名称
- 是否包含“已有”标记

只有带“已有”的种子才进入后续详情查询。

### 详情页

从详情页中识别：

- 种子名称
- 成熟时间

如果未匹配到成熟时间，则输出“未解析到成熟时间”。

## 输出

脚本直接打印到控制台。

建议输出格式：

```text
种子ID=10001 名称=xxx 成熟时间=6时30分
种子ID=10002 名称=yyy 成熟时间=12时00分
```

如果没有找到任何已有稀有种子，则输出：

```text
未发现已有稀有种子
```

## 实现位置

脚本放在：

- `get_seeds/query_rare_seed_inventory.py`

不修改现有 `ygmc` CLI 结构。

## 错误处理

- 请求失败：打印中文错误并继续下一个页面或种子
- 某个详情页失败：只跳过该种子，不中断整批输出
- 页码解析失败：默认只处理第一页

## 验证

完成后至少验证：

1. 语法校验通过
2. 能成功请求商店页
3. 能输出至少一条 `seedId + 成熟时间` 或明确输出“未发现已有稀有种子”
